Перед вам Simple Paint, в нём можно:
-Рисовать мышью и клавиатурой
-Создавать заливку
-Выбирать цвет пера
Небольшая инструкция по использованию:
1. Перемещение пера - перемещать перо можно с помощью мыши или с помощью клавиш 'Right', 'Left', 'Up', 'Down'.
2. Изменение цвета - есть восемь цветов, которые можно вызвать с помощью букв 'g' (зелёный), 'b' (синий), 'y' (жёлтый), 'v' (сиреневый), 'p' (фиолетовый), 't' (желтовато-коричневый), 'o' (оливковый), 'r' (красный)
3. Заливка, начало заливки - 'i', конец заливки - 'e'.

Поделиться этим проектом можно по ссылке: https://learn.algoritmika.org/share/59220499
